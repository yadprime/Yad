# YAD God's Hand Website

Premium multi-page Next.js website for YAD God's Hand, focused on the YAD Tech & Digital Aid launch division in Sierra Leone.

## Routes

- `/` Home
- `/about`
- `/services`
- `/process`
- `/vision`
- `/contact`

## Contact placeholders

Replace the first-version WhatsApp and email values in `src/lib/content.ts`:

- `contact.whatsappNumber`
- `contact.whatsappDisplay`
- `contact.email`
- `contact.defaultMessage`

## Assets

Brand imagery lives in `public/brand`:

- `yad-hero-wide.png`
- `yad-logo-square.png`
- `yad-coming-soon.png`

## Development

After npm access is available:

```bash
npm install
npm run lint
npm run build
npm run dev
```

The UI/UX Pro Max workflow was initialized into `.codex/skills`.
